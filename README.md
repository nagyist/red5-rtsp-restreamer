red5-rtsp-restreamer
=============

Example code for Red5 server which demonstrates how to stream from an RTSP source (Specifically an Axis camera) to a live Flash media stream. The code was developed by Andy Shaules and donated to the Red5 project by [Infrared5, Inc](https://www.red5.net/). This repo is no longer maintained by the Red5 open source team. 

For current RTSP restreaming functionality, see the Red5 Pro Restreamer documentation: [Restreamer](https://www.red5.net/docs/red5-pro/users-guide/restreamer/)

[Red5 Pro Server](https://www.red5.net/red5-pro/low-latency-streaming-software/) provides and maintains a newer more capable plugin for your RTSP or MPEG-TS needs.
